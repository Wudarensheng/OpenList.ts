# OpenList.ts Driver 架构重构计划

## 目标

参考 OpenList (Go) 的 driver 架构，重构 `src/drivers/` 目录结构：
- 每个 driver 独立文件（如 `drivers/s3.ts`）
- 统一由 `drivers/registry.ts` 调度
- 适配 Cloudflare Workers 无状态环境

## 当前结构

```
src/drivers/
├── types.ts              # 核心接口定义
├── registry.ts           # Driver 注册表 + 调度
├── s3.ts                 # S3 Driver
├── onedrive.ts           # OneDrive Driver
├── aliyundrive_open.ts   # 阿里云盘 Driver
├── pikpak.ts             # PikPak Driver

```

## 实施步骤

### Phase 1: 重构核心类型 (`types.ts`)

参考 OpenList 的 `internal/driver/` 设计，增强核心接口：

```typescript
// 新增：Driver 能力标记接口
export interface MkdirCapable { mkdir(path: string, config: Config): Promise<void>; }
export interface RenameCapable { rename(path: string, newName: string, config: Config): Promise<void>; }
export interface CopyCapable { copy(src: string, dst: string, config: Config): Promise<void>; }
export interface MoveCapable { move(src: string, dst: string, config: Config): Promise<void>; }
export interface RemoveCapable { remove(path: string, config: Config): Promise<void>; }
export interface PutCapable { put(path: string, file: ArrayBuffer, contentType: string, config: Config): Promise<void>; }

// Driver 基础接口（只包含 list + link，其他为可选）
export interface Driver {
  config(): DriverConfig;
  init(config: Config): Promise<void>;
  list(path: string, config: Config): Promise<ListResult>;
  link(path: string, config: Config): Promise<LinkResult>;
  get?(path: string, config: Config): Promise<Obj>;
}

// 完整 Driver（实现所有操作）
export interface FullDriver extends Driver, MkdirCapable, RenameCapable, CopyCapable, MoveCapable, RemoveCapable, PutCapable {}
```

**关键变更：**
- `config` 参数类型从 `Record<string, any>` 改为具体类型或泛型
- 拆分 Driver 接口为基础（list + link）+ 可选能力接口
- 参考 OpenList 的 `Obj` 接口，统一文件对象模型

### Phase 3: 实现注册机制

参考 OpenList 的 `op.RegisterDriver()` 模式，但适配 TypeScript：

```typescript
// src/drivers/registry.ts

import type { Driver, DriverConfig, DriverInfo } from './types';

// Driver 工厂函数类型
type DriverFactory = () => Driver;

// 注册表
const driverRegistry = new Map<string, {
  factory: DriverFactory;
  info: DriverInfo;
}>();

// 注册函数（各 driver 的 meta.ts 调用）
export function registerDriver(
  name: string,
  factory: DriverFactory,
  info: DriverInfo
): void {
  driverRegistry.set(name, { factory, info });
}

// 获取 driver 实例（每次创建新实例，适配 Workers 无状态）
export function createDriver(name: string): Driver {
  const entry = driverRegistry.get(name);
  if (!entry) throw new Error(`Driver not found: ${name}`);
  return entry.factory();
}

// 获取 driver 配置信息
export function getDriverInfo(name: string): DriverInfo | undefined {
  return driverRegistry.get(name)?.info;
}

// 获取所有已注册 driver 名称
export function getDriverNames(): string[] {
  return Array.from(driverRegistry.keys());
}

// 获取所有 driver 信息（用于 admin API）
export function getDriverInfoMap(): Record<string, DriverInfo> {
  const map: Record<string, DriverInfo> = {};
  for (const [name, entry] of driverRegistry) {
    map[name] = entry.info;
  }
  return map;
}

// 导入所有 driver（触发注册）
// 这替代了 Go 的 all.go 模式
import './s3/meta';
import './onedrive/meta';
import './aliyundrive_open/meta';
import './pikpak/meta';
import './dropbox/meta';
```

### Phase 5: 更新调用方

**`src/routes/fs.ts` 变更：**
```typescript
// 旧代码
import { getDriverInstance } from '../drivers/registry';
const driver = await getDriverInstance(storage.driver, JSON.parse(storage.addition));

// 新代码
import { createDriver } from '../drivers/registry';
const driver = createDriver(storage.driver);
await driver.init(JSON.parse(storage.addition));
```

**关键变更：不再缓存 driver 实例**
- Cloudflare Workers 的 isolate 模型下，模块级缓存不可靠
- 每次请求创建新实例 + init，开销很小（只是设置配置，不做网络请求）
- 如果 driver 需要 token refresh，由 driver 内部管理（参考 `base.ts` 的 TokenManager）

### Phase 6: Cloudflare Workers 适配

**无状态设计原则：**
1. **不依赖模块级缓存**：`driverInstances` Map、`pathIdCache` Map 等都会在 cold start 时丢失
2. **Token 管理**：每次请求时检查 token 有效性，过期则 refresh（driver 内部处理）
3. **路径缓存**：如果需要缓存 path→ID 映射，使用 D1 数据库而非内存
4. **Bundle 优化**：考虑用 `@aws-sdk/core` + 单独命令包替代完整 `@aws-sdk/client-s3`

**D1 缓存路径 ID（替代内存 Map）：**
```sql
CREATE TABLE IF NOT EXISTS path_id_cache (
  driver_name TEXT NOT NULL,
  path TEXT NOT NULL,
  file_id TEXT NOT NULL,
  expires_at TEXT NOT NULL,
  PRIMARY KEY (driver_name, path)
);
```

## 验证方案

1. **类型检查**：`npm run typecheck` 确保无类型错误
2. **本地开发**：`npm run dev` 启动 wrangler，测试 API 端点
3. **功能测试**：
   - `GET /api/admin/driver/list` 返回所有已注册 driver
   - `POST /api/admin/storage/create` 创建 S3 存储
   - `POST /api/fs/list` 列出文件
   - `POST /api/fs/get` 获取文件信息 + 下载链接
4. **部署测试**：`npm run deploy` 部署到 Cloudflare Workers

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Bundle size 超限 | 部署失败 | 考虑 S3 REST API 替代完整 SDK |
| 路径 ID 缓存失效 | 性能下降 | 添加 D1 缓存表，设置合理 TTL |
| Token refresh 竞态 | 请求失败 | 使用 D1 锁或接受偶尔的 refresh 重试 |
| 旧文件删除遗漏 | 代码混乱 | 迁移完成后统一删除旧文件 |
